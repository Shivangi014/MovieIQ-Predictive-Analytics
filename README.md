# 🎬 MovieIQ – Predictive Analytics on Film Success

MovieIQ is a Machine Learning project that predicts whether a movie will be successful based on features like budget, popularity, runtime, and vote average.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- SciPy
- Matplotlib
- Seaborn
- Streamlit
